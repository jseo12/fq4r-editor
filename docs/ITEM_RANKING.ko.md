# AI추천정렬 기준

이 정렬은 `item-details.json`의 능력치 보정, 속성 마스크, 효과 설명을 비교합니다. **게임이 정의한 공식 등급이 아닌 에디터의 편의용 점수**입니다. 직업·전장·다른 장비와의 조합에 따라 실제 유용성은 달라집니다.

버튼명은 `AI추천정렬`이며 외부 AI 서비스 호출 없이 로컬의 고정 점수 규칙으로 정렬합니다.

## 점수

```
점수 = AT×2 + AR + DF×2 + DR
     + 서로 다른 속성 수×4
     + 설명의 유용한 효과 가점
     - 설명의 불리한 효과 감점
```

- 능력치의 음수 보정은 그대로 감점합니다.
- F/E/A/W 속성은 마스크 `11/22/44/88`별로 한 번씩만 계산합니다. 공격·내성의 실제 효용이 같다는 검증을 뜻하지 않습니다.
- 원본 설명과 대체 설명에서 공백을 제거하고 키워드를 비교합니다. 같은 효과 규칙은 중복 가산하지 않습니다.
- 설명의 효과가 실제 게임에서 발동하는지 또는 그 효과 크기까지 검증한 순위는 아닙니다. 예를 들어 설명과 실제 구현 차이가 있는 아이템은 이후 별도 조정할 수 있습니다.
- 가격·보유 수량·감정 여부는 점수에 사용하지 않습니다.
- 점수 내림차순, 동점이면 Item ID 오름차순입니다. 기존 중복 ID는 수량과 상대 순서를 유지합니다.
- 정의가 없는 ID는 -1000점으로 맨 뒤에 두며 삭제하지 않습니다.

## 데이터 반영

버튼을 누르면 아이템 ID·수량 쌍을 위 순서로 실제 세이브 메모리의 첫 슬롯부터 채우고, 남는 슬롯은 0으로 비웁니다. 감정 데이터·캐릭터 장착 아이템·골드 등은 변경하지 않습니다. 체크섬은 기존 편집 방식대로 파일 저장 시 갱신합니다. 전체리셋으로 처음 불러온 순서와 수량·감정 상태로 복원할 수 있습니다.

가중치는 `packages/save-core/src/item-ranking.json`, 계산은 `itemQualityScore()`, 정렬은 `editInventory({ type: 'sort-quality' })`에 정의되어 있습니다.
