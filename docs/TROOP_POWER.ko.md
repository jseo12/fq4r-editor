# 부대 목록과 POWER

부대 탭의 컬럼은 `NATION | NO | NAME | ALL | POWER | MAP-NAME | ROSTER`입니다.

- NATION: `+05` 하위 니블의 국가명·색상과 `+00`의 소속·활동 상태를 조합합니다. 비활성은 `(비활성)`, 그 외 카리온 아닌 아군은 `(아군)`, 양산형은 `(양산형)`을 붙입니다. 적군·중립과 원시 상태 코드는 접미사로 표시하지 않습니다.
- NO: 전체 상태 `+00=00`이면 저장 ID `+06`에 1을 더해 표시합니다. 그 외 상태는 저장 ID 그대로 표시합니다.
- NAME: 첫 부대원 이름입니다. 이름 ID 0은 `(이름없음)`이며, 상태 00·저장 ID 252~254는 `병사1`~`병사3`으로 표시합니다.
- ALL: `+01`의 인원 수입니다.
- MAP-NAME: `+02~03`에서 상위 바이트가 01일 때 내부 이름을 사용합니다. 나머지는 하위 바이트의 외부 이름을 표시합니다. 상태가 00이 아니면 +03은 강화값으로도 쓰이므로 위치 편집은 +02만 변경합니다.
- ROSTER: 부대원 직업 이미지를 원본 순서로 표시합니다. 32×32 CSS 픽셀에 1x/1.5x/2x를 지원하며, 공간이 부족하면 일부 이미지와 말줄임표를 표시합니다.

상태 00·저장 ID 252~254의 병사부대는 POWER를 계산하지 않고 `-`로 표시합니다. 다른 부대의 POWER는 아래 식을 사용합니다. 이 식의 상태 판정은 국가명과 별개인 전체 `+00` 값입니다.

## POWER 계산

계산 요약:

```text
POWER = 헤더 +00 != 0이면 (헤더 +03) × ALL × 6, 아니면 0
각 부대원마다:
  S = 보정된 AT + AR + DF + DR
  직업 플래그 & E0 != 0이면 S *= 2
  H = HR 하위 4비트
  적십자(item 2D)를 장착하고 H != 0이면 H += 5 (최대 16)
  H == 0이면 H = 16
  POWER += (floor(HP / 2) + S + H × 6) × 2
최종 POWER = min(POWER, 99999)
```

`+03`은 활성 아군(상태 00)에서는 맵 상위 바이트이며, 그 외 상태에서는 POWER 가산값으로 사용합니다.
AT/AR는 피로 4회마다, DF/DR는 피로 1회마다 감소하는 경로와 하한을 반영합니다.
장비 덧셈은 게임의 u8 wrap 및 상한 처리를 유지하고, 의상 코드 85/89/8A/8B/8C의 추가 보정을 적용합니다.
원본 기본 능력이나 세이브 바이트를 변경하지 않습니다.

참조된 캐릭터가 숨겨진 빈 동적 슬롯 등으로 읽히지 않으면 POWER는 `—`, 해당 ROSTER 위치는 `?`로 표시합니다.
부대원 참조는 배열 순번으로 조회하지 않고 원본 캐릭터 슬롯 ID로 조회합니다.

## 구현 및 검증

- 계산: `packages/save-core/src/index.ts`의 `troopPower`, `characterPower` 및 내부 `troopStat`.
- 고정 테이블: `packages/save-core/src/power-tables.json`.
- 화면: `apps/web/src/Troops.tsx`, 공통 이미지: `ClassImage.tsx`.
- 단위 테스트: HP 홀수 절삭, 피로, 장비·의상·직업 플래그, HR 특수값, 중복 참조, 99999 상한, 빈 참조.
- UI 테스트: 컬럼 순서, 헤더 필드, 리더 이름, 지역, POWER, 동적 슬롯 이미지 조회 및 한 줄 정렬.

부대 편성의 개별 POWER는 `characterPower`에 상태가 00이 아닌 부대의 +03×6을 더합니다. 부대 합계는 99,999로 제한합니다.

캐릭터 탭에도 개인 POWER를 CLASS 다음에 표시합니다. 이 값은 부대 헤더의 +03 강화 가산을 제외한 `characterPower` 결과이며, 화면 너비에 관계없이 숨기지 않습니다. 편집에 따라 다시 계산하고 최초 값과 비교해 강조합니다.


## 랭킹의 LV 99 POWER

랭킹 탭은 현재 레벨에서 LV 99까지 게임 성장식을 적용했을 때 도달 가능한 개인 POWER의 최소~최대 범위를 표시하고, 최대값 내림차순(동률은 ID 오름차순)으로 정렬합니다. RANK는 선택한 필터 내에서 1부터 연속으로 표시합니다.

HP는 레벨마다 4~6 성장하고 최대 999입니다. AT/DF/AR/DR은 기존 레벨에 따른 순환 성장과 99 상한을 적용합니다. 기존 레벨이 16의 배수인 성장 단계에서 AA/AD/MD/HR 중 하나가 성장합니다. POWER에 영향을 주는 HR의 도달 가능한 결과를 모두 탐색하여 범위를 구합니다. HR의 0=16 표현을 반영하며 적십자 등 아이템 보정은 적용하지 않습니다.

랭킹의 현재 POWER와 LV 99 POWER는 아이템·피로도 보정을 제외하고 현재 직업만 유지합니다. 레벨 50 전직 조건은 성장 함수에서 처리하지만 직업 변경 자체는 자동 수행하지 않습니다. 이미 LV 99 이상이면 추가 성장 없이 현재 POWER를 양쪽에 표시합니다. 계산은 복사본에서만 수행하며 세이브 바이트와 체크섬은 변경하지 않습니다. 이는 성장 난수에 따른 가능 범위이며 평균이나 확률 예측은 아닙니다.

표시 범위는 캐릭터 탭과 공유합니다. 수정한 캐릭터 필터는 랭킹에 표시하거나 적용하지 않습니다. 기존 능력치 컬럼에는 동일한 반응형 규칙을 적용하고 RANK·Lv99 POWER는 항상 표시합니다. 화면 너비 1200px 미만에서는 현재 POWER, 1100px 미만에서는 LV를 순차적으로 숨깁니다. HP 등은 기존 규칙대로 960px 미만에서 숨깁니다.

랭킹의 LV·HP·HR·AT·AR·DF·DR·AA·AD·MD는 LV 99 성장 기준의 기본 능력치입니다. 고정값은 숫자로, 무작위 성장으로 달라지는 값은 최소~최대 범위로 표시합니다. AD·MD는 저장 감소량을 30에서 뺀 표시값을 사용합니다. 각 능력치의 최대값은 개별 가능 범위이며, 추가 성장 기회를 나눠 쓰므로 모든 능력치 최대값을 동시에 얻을 수 있다는 뜻은 아닙니다. 캐릭터 탭의 현재 능력치 및 POWER 계산은 기존 기준을 유지합니다.


랭킹 마지막의 SKILL은 현재 세이브의 직업별 등록 마법 목록을 기준으로 `마법`, `소환`, `-`를 표시합니다. 말아레스(BF)는 아레스(06)의 목록을 사용합니다. 소환 마법은 용소환(02), 사자소환(03), 정령소환(04), 천사소환(05), 사신소환(14)입니다. 캐릭터의 현재 선택 마법이나 장비 부여 마법은 이 판정에 사용하지 않습니다. 실제 전투의 일시적 상태나 사용 제한까지 판정하는 값은 아닙니다. SKILL은 기존 캐릭터 표와 같이 화면 너비 1600px 미만에서 숨깁니다.
