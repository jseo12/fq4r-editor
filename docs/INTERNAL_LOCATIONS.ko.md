# 내부 맵 상세 이름

내부 맵 `0x0100~0x01FF` 256개 ID의 표시 이름을 언어별로 제공합니다. 아래 상세 이름 구성은 한국어 목록에 해당합니다.

- 253개: DOS판과 같은 숫자 ID의 상세 이름을 참고용 레이블로 사용합니다.
- 3개(`0x01E6`, `0x01FE`, `0x01FF`): DOS판 이름이 없으므로 FQ4R에서 확인된 소속 지역명과 `(내부 0xXXXX)`를 표시합니다.

| ID | 상세 표시명 | 기존 FQ4R 표시명 |
|---|---|---|
| 0x0100 | 링커-촌장 | 링커마을 |
| 0x0101 | 링커-상점 | 링커마을 |
| 0x014A | 카리온-회의실 | 카리온성 |
| 0x0154 | 바르시아-대전 | 바르시아성 |
| 0x01F3 | 오프닝-제넬루 아레스 | 카리온성 |

## 표시상의 한계

게임은 내부 ID를 소속 지역 ID로 변환하여 지역 이름을 표시합니다.
따라서 기존 이름표만으로는 같은 지역 안의 방·동굴·이벤트를 구분할 수 없습니다.

DOS판의 상세 이름은 같은 ID를 기준으로 가져온 참고용 레이블입니다. FQ4R에서 모든 방의 용도까지 개별 검증한 결과는 아닙니다.
맵 리소스 이름만으로 방의 용도를 단정하지 않았으며, 출처를 확인할 수 없는 이름을 새로 만들지 않았습니다.
원래 지역 표시명은 각 언어의 `locations.json`에 보관합니다.

## 구현

- `packages/save-core/src/game-data/ko/internal-locations.json`: 상세 이름표.
- `locationName`: 선택 언어의 내부 이름을 먼저 조회하고 지역명으로 대체합니다. 일본어는 소속 지역명이며 한국어의 상세 방 이름을 임의로 번역하지 않습니다.
- `troopLocationName`: 상위 바이트 01이면 내부 이름을 사용하며, 00 또는 다른 값이면 하위 바이트의 외부 지역명을 사용합니다.
- 원본 세이브의 위치 값은 변경하지 않습니다.

일본어 데이터는 `game-data/ja/internal-locations.json`에 있습니다. 예를 들어 0x0100은 `リンカーの町`, 0x014A는 `カーリオンの城`로 표시합니다. ID는 그대로이며 여러 내부 ID가 같은 이름을 가질 수 있습니다.
