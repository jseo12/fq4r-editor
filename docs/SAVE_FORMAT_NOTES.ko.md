# FQ4R 세이브 형식 및 표시 규칙

## 검증과 주요 오프셋

오프셋은 파일 시작 기준 16진수이며, 다중 바이트 값은 little endian입니다.

| 항목 | 위치·형식 |
|---|---|
| 고정 크기 | `0x8000`바이트 |
| signature | `0x0000`: `[Ww]in4` |
| 플레이 시간 | `0x0200`: u32, 분 |
| 목록 미리보기 위치 ID | `0x0204`: u16 |
| 난이도 포함 플래그 | `0x020C`: u16 |
| 가방 | `0x0492`: ID/수량 각 1바이트, 256슬롯 (형식상 공간; UI의 등록 상한은 72개) |
| 골드 | `0x0692`: u32, 저장 단위 10G ([단위 재검사](GOLD.ko.md)) |
| 아이템 감정 여부 | `0x0696~0x06DD`: 72바이트; 아이템 성능이 아님 |
| 마법 목록 | `0x06DE~0x07F5`: 직업 ID, 개수, 마법 ID 목록; `FF` 종결 |
| 캐릭터 | `0x09A6`: 640개 × 32바이트 |
| 부대 목록 | `0x59A6~0x79A5`: 16바이트 헤더 + 인원수 × u16 참조; `FF` 종결 |
| XOR 체크섬 | `0x7DA6~0x7DAD`: 4096바이트 블록별 1바이트 |

체크섬 8바이트 전체를 계산에서 제외해야 합니다. 특히 마지막 블록에는 저장 체크섬 영역 자체가 들어 있습니다.

## 난이도

세이브 목록에서는 `0x020C`의 u16 플래그를 다음처럼 해석합니다. 다른 비트는 난이도 선택에 사용하지 않습니다.

| `flags & 0x18` | 추가 조건 | 표시 |
|---|---|---|
| `0x00` | 없음 | 처음 |
| `0x08` | 없음 | 초보 |
| `0x10` | 없음 | 보통 |
| `0x18` | `flags & 0x40 == 0` | 능숙 |
| `0x18` | `flags & 0x40 != 0` | 고투 |

## 위치와 캐릭터

미리보기 위치 `0x0204`와 현재 컨텍스트 맵 `0x048E`, 각 부대의 현재 맵은 별개입니다. 현재 화면에서는 `0x0204`를 목록 위치로 사용합니다.

확보한 위치 ID/이름 테이블은 기본 지역과 내부 맵 표시 이름 매핑을 포함합니다. 같은 이름이어도 같은 맵 ID라는 뜻은 아닙니다. 미확정 ID는 숫자를 남기고 알 수 없는 지역으로 표시합니다.

아레스는 캐릭터 인덱스 220, 레코드 시작 `0x2526`, 이름 ID `0x001A`입니다. 커뮤니티의 `0x252C`는 레코드 시작보다 6바이트 뒤이며 별도 시작점으로 취급하지 않습니다. 부대 멤버 참조는 캐릭터 번호 자체가 아니라 번호 × 32입니다.

## 현재 읽기 범위와 제한

크기·signature 오류는 로딩을 차단합니다. 체크섬은 비교하되 불일치해도 내용을 읽고 개요 표의 영역별 정상 여부만 표시합니다. 게임 로더의 엄격한 체크섬 거부와 달리 HEX 편집 중인 파일도 열기 위한 에디터 정책입니다. 부대·마법 가변 목록은 경계와 참조를 확인하고 미해석 구조를 만나면 경고와 함께 해당 목록의 추가 해석을 중단합니다. 미해석 값을 삭제·정규화하지 않습니다.

개요·캐릭터·아이템·부대·마법을 메모리에서 편집할 수 있습니다. 웹에서는 다운로드하고 데스크톱에서는 백업 저장 또는 다른 이름으로 저장합니다. 출력 전에 8개 체크섬을 맞춥니다. 정상 체크섬만으로 게임 내 상태의 의미적 유효성을 보장하지 않습니다.

## 캐릭터 표시 컬럼

캐릭터 표는 `ID | LEAD | NAME | CLASS | POWER | LV | HP | HR | AT | AR | DF | DR | AD | AA | MD | FT | EL+ | ITEM | SKILL` 순서입니다.

- LEAD: 레코드 +07의 지휘 관련 값. AA: +10의 기초 투사 공격 값. FT: +0A의 피로.
- HR: +19의 0을 16으로 표시하며 아이템 2D의 +5/cap16 규칙을 적용합니다.
- AD: `30 - min(+11, 30)`. MD: `30 - min(+12, 30)`이며 아이템 1A/20이면 40으로 표시합니다. 편집 UI도 변환된 AD·MD 값을 사용합니다.
- EL+: 저장된 +08 플래그의 10/20/40/80 비트를 F/E/A/W로 표시합니다. 클래스 고유 내성과 런타임 전투 보정을 합산한 값은 아닙니다.
- SKILL: +17의 선택 마법 ID. ITEM: +15의 장착 아이템 ID.

레코드의 기초 AT/AR/DF/DR과 AA를 사용하며 전체 전투 상태나 장비 보정 결과를 재현하는 화면은 아닙니다. 목록 표시만으로 저장값을 변경하지 않으며, 편집 조작은 메모리 데이터에 반영합니다.

## 변경 기준과 파일 출력

변경 강조와 RESET은 파일을 처음 읽은 데이터를 기준으로 합니다. 저장·다운로드만으로 기준을 바꾸지 않습니다. 데스크톱에서 외부 변경을 감지하면 세이브 다시읽기 버튼이 나타나며, 다시 읽으면 편집 내용과 RESET 기준을 최신 파일로 교체합니다. 체크섬 표는 일반 편집 시 유지하고, 개별 체크섬 수정 또는 파일 출력 시 갱신합니다.

캐릭터 목록의 POWER는 `characterPower`로 장비·피로도·직업 플래그·HP·HR을 반영한 개인 전투력을 계산합니다. 부대 헤더 +03의 가산은 포함하지 않습니다. CLASS 다음에 표시하며 모든 반응형 구간에서 유지합니다. 값에 영향을 주는 필드를 편집하면 즉시 갱신하고, 최초 개인 POWER와 다를 때 변경 강조를 적용합니다. 계산값 자체를 세이브에 기록하지 않습니다.

캐릭터 목록의 ID는 파일의 캐릭터 슬롯 번호(0~639)이며 표시용 순번이 아닙니다. 변경이 있는 레코드는 ID 뒤에 `*`를 붙입니다. 부대 편성 목록의 NO는 부대 내 순번으로 별도 유지합니다.
