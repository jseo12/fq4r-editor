# 캐릭터 이름 데이터

캐릭터 이름은 이름 ID별 테이블에서 조회합니다.

## 파일

`packages/save-core/src/game-data/ko/`와 `packages/save-core/src/game-data/ja/`에 언어별로 보관합니다. 아래 한국어 자료의 기존 슬롯 구성은 유지합니다.

| 파일 | 내용 |
|---|---|
| `character-names.json` | 이름 ID → 복원 이름. 658슬롯 중 비어 있지 않은 이름 649개 |
| `class-names.json` | 직업 ID → 기존 복원 이름. 256개 후보 레코드 중 비어 있지 않은 이름 221개, 빈 문자열 2개, 미복원 `null` 33개 |

이름 테이블은 10바이트 슬롯 658개에 해당합니다. 슬롯이 존재한다고 모두 게임에서 사용된다는 뜻은 아닙니다.

## 표시 규칙

- 캐릭터 레코드의 `+02` u16 값을 이름 ID로 사용합니다. 캐릭터 배열 번호나 직업 ID와 혼동하지 않습니다.
- 이름 ID가 0이 아니면 `character-names.json`에서 조회합니다.
- 이름 ID가 0이면 에디터에서는 `(이름없음)`으로 표시합니다. 게임의 직업명 대체 규칙은 적용하지 않습니다.
- 테이블에 없거나 복원되지 않은 값은 ID를 포함한 `이름 미확인` 또는 `직업 미확인`으로 표시합니다.
- 아레스는 이름 ID `0x001A`, 애레인은 `0x0209`입니다. 한국어 선택 시 한글 표기를, 일본어 선택 시 일본어 원문 이름을 표시합니다. 영어 선택 시 이름 데이터는 한국어를 사용합니다.

이름 658슬롯은 기존 해독기로 모두 변환되었지만, 기존 직업명 후보 자료의 미복원 33레코드는 그대로 유지했습니다. 일부 후보 레코드가 실제 이름 데이터인지도 확정되지 않았으므로 커뮤니티 이름으로 임의 보충하지 않습니다.

## 목록과 편집

기본 목록은 NPC 슬롯 0~219를 숨깁니다. 표시 범위 드롭다운과 수정한 캐릭터만 표시 필터를 함께 사용할 수 있고, 수정한 캐릭터 필터는 변경이 있을 때만 활성화됩니다. 이름 없는 고정 슬롯은 삭제하지 않습니다. 529~639의 동적 슬롯은 32바이트 전체가 0일 때만 제외합니다.

캐릭터 목록의 편집창은 현재 필터 결과 순서로 이전·다음 캐릭터를 엽니다. 부대 편성에서 더블 클릭한 경우에는 해당 부대원 또는 캐릭터 목록 순서를 사용합니다.

일본어는 이름 ID 0~657의 658칸과 직업 ID 0~219의 220개 이름을 제공합니다. 직업 ID 220~255는 이름이 확인되지 않아 `null`로 유지하며 미확인 표시를 사용합니다. 반각 가나 원문은 데이터 파일에 보존하고 표시할 때만 정규화합니다. 자세한 내용은 [게임 이름 데이터](GAME_NAMES.ko.md)를 참고하세요.
