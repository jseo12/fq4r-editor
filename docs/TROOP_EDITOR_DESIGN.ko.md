# 부대 편집 UI와 데이터 동작

이 문서는 현재 구현을 기준으로 합니다. 바이트의 의미는 [부대 헤더 형식](TROOP_HEADER.ko.md), POWER는 [계산식](TROOP_POWER.ko.md)을 참고합니다.

## 목록과 필터

컬럼은 `NATION | NO | NAME | ALL | POWER | MAP-NAME | ROSTER`입니다.

- 상태 +00이 정확히 00인 부대를 먼저 저장 ID 오름차순으로 정렬합니다. 나머지는 +05 하위 국가 코드, 저장 ID 순입니다. 표시 정렬은 실제 데이터 순서를 바꾸지 않습니다.
- 상태 00의 NO는 저장 ID+1입니다. 상태 00·저장 ID 252~254의 이름은 병사1~3이며 POWER는 `-`입니다.
- 기본 필터는 네임드 부대입니다. 첫 부대원의 이름 ID가 0보다 크거나 특수 병사부대이면 포함합니다.
- 아군 필터는 상태 00 또는 30인 부대를 대상으로 합니다. 비활성(상위 니블 30)은 별도 체크박스가 켜진 경우에만 보입니다.
- 전체 부대를 선택하면 비활성 보기까지 켭니다. 이후 체크박스를 끄면 전체 필터에서도 비활성은 숨깁니다.
- NATION은 +05 하위 국가 코드로 이름과 색상을 선택합니다. 상태 상위 30은 `(비활성)`을 붙이고 아군 표시는 생략합니다. 그 외 카리온 아닌 아군만 `(아군)`, 상위 D는 `(양산형)`을 표시합니다.
- NATION은 메인 부대 목록에서 180px 고정폭과 말줄임표·툴팁을 사용합니다.

## 모달과 부대 정보

행 클릭 또는 Enter/Space로 엽니다. 헤더에는 NO, 부대장 직업 이미지와 `이름 · N명`, 16바이트 HEX, RESET과 닫기 버튼을 표시합니다. RESET은 확인 후 로딩 기준 데이터로 복원합니다.

탭은 `부대 정보`와 `부대 편성`이며 변경은 메모리에 즉시 반영합니다. 파일 출력은 상단 저장·다운로드로 수행합니다.

| 항목 | 위치 | 편집 동작 |
|---|---|---|
| 소속 / 활동 상태 | +00 하위 / 상위 니블 | 각각 수정하고 반대 니블 보존 |
| 국가 / 국가 표시 그룹 | +05 하위 / 상위 니블 | 각각 수정하고 반대 니블 보존 |
| NO | +06 | 상태 00이면 UI 1~256을 저장 ID 0~255로 변환 |
| MAP-NAME(현재위치) | +02~03 | 상태 00은 u16, 나머지는 +02만 수정 |
| 이동 명령 / 목적지 | +0A | 없음, 지정 지역, FE 주인공 추적, FF 자동 목표 |
| 전투 강화값 | +03 | 상태가 00이 아닐 때 별도로 편집 |

알 수 없는 외부 지역은 선택 목록에서 제외합니다. 기존 저장값이 미등록이면 해당 값을 표시하여 보존합니다. 위치·이동 명령·목적지는 자연스러운 그리드 순서로 배치하며 부대 매크로는 그 다음에 배치합니다.

추가 부대 정보에는 +04 진입 배치/출현 대기값, +0B 복제 원본 ID, +0C~0D 이전·복귀 위치, +0E 상위 진행 조건과 미확인 하위 니블, +07/+08/+09/+0F 원시 HEX 편집을 제공합니다. 진행 조건의 사건명과 미확정 필드는 임의로 해석하지 않습니다.

## 부대 매크로

일반 아군은 전체 상태 00이며 저장 ID 252~254 병사부대는 번호·인원 상한 검사에서 제외합니다. 현재 일반 아군의 최대 ID+1을 사용하고 빈 번호를 재사용하지 않습니다. 상한은 20개·저장 ID 0~19이며 저장 공간이 부족해도 실패합니다. 실패 시 원본 데이터는 바뀌지 않습니다.

- **아군부대로 복제:** 헤더와 부대원 참조를 새 레코드로 복사합니다. 캐릭터 32바이트 자체는 복제하지 않아 참조된 캐릭터 편집은 양쪽에 반영됩니다. 상태 00, 국가 카리온(+05=00), 현재 위치 카리온성(0001), 이동 명령 00으로 설정합니다.
- **강제 아군부대 편입:** 현재 레코드를 상태 00과 새 ID로 변경합니다. 국가 표시 상위 니블은 0으로 바꾸고 하위 국가 코드는 유지합니다. 비아군 +03 강화값은 지웁니다. 이미 상태 00인 부대에서는 비활성화합니다.
- **이 부대 강제 삭제:** 게임 버그·충돌 가능성을 알리는 확인 후 레코드를 제거합니다. 캐릭터 레코드는 삭제하지 않고 남은 부대의 ID도 재부여하지 않습니다. 상태 00·저장 ID 00 주인공 부대에서는 비활성화합니다.

## 편성 배치와 비교 필터

기본은 2단입니다. 1단은 현재 부대만, 나머지는 같은 행에 제2~제5부대를 표시합니다. 화면 너비가 줄어도 아래 행으로 쌓지 않으며 사용 가능한 단수로 자동 축소합니다.

| 보기 | 화면 너비 조건 |
|---|---|
| 현재 부대만 / 2단 | 항상 제공 |
| 3단 | 840px 이상 |
| 4단 | 1120px 이상 |
| 5단 | 1400px 이상 |

각 비교 영역 위에 부대 필터·캐릭터 필터 드롭다운과 부대 목록으로 돌아가는 ↶ 아이콘을 표시합니다. ↶는 부대를 선택한 상태에서만 보입니다. 부대 미선택이면 제목은 제N부대, 선택하면 `NO N · 부대장명 · N명`, 캐릭터 목록이면 필터명·인원 수입니다.

- 부대 필터: 아군·네임드·전체. 모달을 열 때 메인 목록의 필터와 비활성 표시 여부를 상속합니다.
- 캐릭터 필터: 아군캐릭터는 활성 상태 00 부대에 포함된 캐릭터의 합집합이며 비활성 부대는 제외합니다. 네임드캐릭터는 슬롯 220 이상·이름 ID>0, 전체캐릭터는 파서가 읽은 전체 캐릭터입니다.
- 각 영역의 필터·선택은 독립적입니다. 단수나 탭을 바꿔도 모달이 열린 동안 유지하며, 모달을 닫으면 초기화합니다.
- NEW 행은 실제 부대에만 표시하며 캐릭터 전체 목록에는 표시하지 않습니다.

## 부대원 선택·교환·이동

선택 행은 배경 #00C300입니다. 같은 대상을 다시 클릭하면 해제하고, 두 번째 대상을 선택하면 다음 작업을 수행합니다.

| 선택 조합 | 동작 |
|---|---|
| 부대원 + 부대원 | 두 슬롯의 u16 캐릭터 참조 교환 |
| 부대원 + 캐릭터 목록 | 해당 슬롯을 선택 캐릭터로 교체 |
| 캐릭터 목록 + 캐릭터 목록 | 데이터 변경 없음 |
| NEW + 같은 부대원 | 해당 부대원을 마지막으로 이동 |
| NEW + 다른 부대원 | 원래 부대에서 빼고 목적 부대 마지막으로 이동 |
| NEW + 캐릭터 목록 | 목적 부대 마지막에 추가 |
| NEW + NEW | 데이터 변경 없음 |

NEW는 인원 18명 미만일 때만 표시합니다. 18명 이상인 기존 레코드를 임의로 자르지 않습니다. 캐릭터 목록에서 교체·추가해도 캐릭터 레코드 자체를 삭제하거나 다른 부대의 참조를 자동 제거하지 않습니다.

부대원 행을 드래그하면 지나가는 대상과 실시간으로 교환하며, 다른 부대나 NEW로도 이동할 수 있습니다. 캐릭터의 소속·수감 플래그는 자동 동기화하지 않습니다.

상태 00·저장 ID 00인 주인공 부대의 첫 슬롯이 캐릭터 220 아레스이면, 이동·교체 전에 게임 문제 가능성을 알리는 confirm을 표시합니다. 취소하면 데이터는 유지하고, 확인한 조작 한 번에만 허용합니다. 단순 선택과 캐릭터 능력치 편집에는 이 확인을 표시하지 않습니다.

## 캐릭터 더블 클릭 편집

현재·제2~제5부대의 부대원 및 캐릭터 목록을 더블 클릭하면 기존 캐릭터 편집 모달을 위에 엽니다. X로 닫으면 편성 화면과 필터·선택 상태를 유지합니다. 이전·다음은 해당 목록 순서이며 양 끝에서는 버튼을 비활성화합니다.

마우스를 누른 캐릭터와 뗀 캐릭터가 다르면 열지 않습니다. 단일 클릭은 더블 클릭과 구분하여 처리하고 드래그 시작 시 대기 중 클릭을 취소합니다.

## 컬럼과 반응형

부대원 목록 전체 컬럼은 `NO | ID | LEAD | NAME | POWER | LV | HP | HR | AT | AR | DF | DR | AD | AA | MD | ITEM | SKILL`입니다. NO는 1부터 시작하는 부대 내 순번, ID는 캐릭터 슬롯 번호입니다. NAME은 32px 직업 이미지와 이름입니다.

아래 기준은 화면 전체가 아닌 각 목록 영역의 실제 너비입니다. 좁은 조건부터 누적 적용합니다.

| 너비 미만 | 추가로 숨기는 부대원 컬럼 |
|---|---|
| 960px | ID, AD, AA, MD, SKILL |
| 760px | AT, AR, DF, DR |
| 560px | LV, HP, HR |
| 400px | ITEM |
| 320px | POWER |
| 240px | LEAD |

따라서 최소 너비에서는 NO·NAME만 표시합니다. 각 영역은 독립적으로 스크롤하며 편성 모달의 남은 높이를 채웁니다.

제2~제5부대 선택 목록은 `NATION | NO | NAME | ALL | POWER | MAP-NAME | ROSTER`입니다.

| 너비 미만 | 추가로 숨기는 부대 선택 컬럼 |
|---|---|
| 840px | MAP-NAME |
| 680px | ROSTER |
| 520px | NATION |
| 400px | POWER |
| 360px | ALL |

ALL은 48px, POWER는 65px 고정폭입니다. ROSTER가 숨겨지면 NAME이 남는 공간을 차지하고 숫자 컬럼은 우측에 놓입니다. 넓은 영역에서는 ROSTER가 여유 공간을 사용하며 이미지가 다 들어가지 않으면 말줄임표를 표시합니다.

## 변경 강조와 RESET

최초 로딩 데이터와 비교하여 강조색 #F7F700을 사용합니다. 원래 값으로 돌아오면 강조와 별표를 해제합니다. 저장만으로 RESET·강조 기준을 바꾸지 않습니다.

- 부대원 행: 슬롯 참조나 캐릭터의 32바이트 중 하나라도 다르면 행 텍스트 전체를 강조하고 NO에 `*`를 붙입니다. 캐릭터 목록은 캐릭터 데이터만 비교합니다.
- 메인 및 비교 부대 목록: 헤더·편성·참조한 캐릭터 중 변경이 있으면 NATION을 제외한 컬럼을 강조하고 부대장 이름 뒤에 `*`를 붙입니다. NATION 색상은 국가색을 유지합니다.
- ROSTER: 해당 위치의 참조 또는 캐릭터 데이터가 달라진 이미지의 배경만 강조합니다. 헤더만 변경하면 이미지 배경은 바뀌지 않습니다.
- 복제한 새 부대는 새 레코드로 표시하며, 다른 부대 삭제로 순번이 이동해도 원래 부대와 대응해 비교합니다.

## 저장 구조와 검증

부대 저장 영역은 8192바이트이며 `16바이트 헤더 + 인원수×u16 참조`를 순서대로 배치하고 FF로 끝냅니다. 참조값은 캐릭터 ID×32입니다. 인원 변동 시 뒤쪽 레코드를 재배치하고 제거된 공간은 지우며 관련 없는 데이터는 보존합니다. 용량·참조·상한 오류는 데이터 변경 전에 거부합니다.

단위 테스트는 직렬화·용량·매크로·아레스 확인 조건을 검사하고, UI 테스트는 다단 배치·필터·반응형·클릭/드래그·NEW·변경 강조·캐릭터 편집 연결을 확인합니다. 모든 편집 조합의 게임 내 동작을 보장하는 것은 아닙니다.
