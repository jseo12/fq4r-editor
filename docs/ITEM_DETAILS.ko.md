# 아이템 능력치 및 설명

`packages/save-core/src/item-details.json`에는 아이템 00~48(빈 항목 포함 73개)의 이름, AT/AR/DF/DR 변화값, 속성 플래그, 가격 및 설명문 2종이 있습니다.

- 에디터는 첫 테이블을 기본 설명으로 사용하고 전각 공백과 연속 공백을 일반 공백 하나로 정리합니다.

화면 너비 1280px 이상에서 NAME과 QTY 사이에 DESC 컬럼이 표시됩니다. 하나 이상의 변화값이 0이 아니면 네 능력치 모두 두 자리 부호 형식으로 표시하고 설명을 이어 붙입니다.

```text
AT+02 AR+02 DF+00 DR+00 짧은 검
AT+20 AR+10 DF+00 DR+05 쉽게 지치지 않도록 함
AT+20 AR+00 DF-05 DR-05 대형 도끼
```

네 변화값이 모두 0이면 설명만 표시합니다. 좁은 화면에서는 DESC를 숨깁니다.
이 데이터는 게임 고정 정의이며 세이브에 능력치나 설명문을 추가로 기록하지 않습니다.
게임의 설명문은 특수 효과의 모든 구현을 증명하지 않습니다. 예를 들어 조건·예외·실제 전투 효과의 세부 내용은 별도 코드 분석이 필요합니다.

## 편집 데이터와 슬롯

슬롯에는 아이템 ID와 수량이 있으며 아이템의 AT/AR/DF/DR 정의는 저장하지 않습니다. 감정 여부는 별도 영역에 아이템 종류별로 저장하므로 같은 종류의 중복 슬롯에도 함께 적용됩니다. ID 48은 감정 영역 밖이므로 감정 상태를 변경하지 않습니다. ID와 오프셋은 이 문서에서 16진수입니다.

- UI 등록 상한은 72개입니다. `ITEM SLOT : N/72`를 표시하고, 상한에 도달하면 추가 버튼 대신 상한 문구를 표시합니다.
- 추가 목록은 이미 보유한 종류를 제외하며 중복 추가도 거부합니다. 새 아이템 수량은 1입니다.
- 삭제하면 뒤쪽 슬롯을 당겨 NO를 다시 매깁니다. 드래그는 이동 중 실시간으로 순서를 바꿉니다.
- 개별 랜덤은 0~99, 전체랜덤은 1~99입니다. 모든아이템획득은 기존 목록을 교체하고 ID 01~48을 각각 99개로 채웁니다.
- 오름차순 정렬과 AI추천정렬은 화면뿐 아니라 실제 슬롯 순서도 변경합니다. 전체리셋은 최초 순서·수량·감정 여부로 복원합니다.
- 미감정은 이름 앞에 전각 `？`를 표시합니다. 수량 변경은 QTY, 감정 변경은 NAME, 슬롯 변경은 NO와 `*`로 강조합니다.
