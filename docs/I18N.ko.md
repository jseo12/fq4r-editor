# 다국어 지원

## 지원 언어와 선택

지원 언어는 한국어 `ko`, 일본어 `ja`, 영어 `en` 세 가지입니다. 지역 코드는 `en-US → en`, `ja-JP → ja`, `ko-KR → ko`로 정규화합니다. 저장된 선택 → 시스템의 우선 언어 목록 중 지원되는 첫 언어 → 한국어 순서로 선택합니다.

로딩 화면과 편집 화면 상단에서 언어를 변경할 수 있습니다. 설정 키는 `fq4r-editor.language`이며 허용값은 `ko`, `ja`, `en`입니다. 저장소를 사용할 수 없어도 현재 실행 중에는 언어를 바꿀 수 있습니다.

언어 변경은 페이지 새로고침이나 편집 컴포넌트의 재생성 없이 반영됩니다. 세이브 바이트·편집값·필터·정렬·RESET 기준은 유지되며 HTML의 `lang` 속성도 변경됩니다.

## 파일 구성

- `packages/save-core/src/locales/ko.json`: 한국어 기본 사전과 메시지 키
- `packages/save-core/src/locales/ja.json`: 일본어 번역
- `packages/save-core/src/locales/en.json`: 영어 번역
- `packages/save-core/src/i18n.ts`: 언어 정규화·번역·자리표시자·변경 구독·숫자 표시
- `apps/web/src/LanguageSelect.tsx`: 언어 선택·초기화·저장·데스크톱 동기화

외부 번역 서비스나 추가 i18n 런타임에 의존하지 않으며, 모든 사전을 앱과 함께 포함합니다. React와 Electron이 같은 사전을 사용합니다.

## 문구 추가와 번역

새 문구는 세 사전에 같은 키로 추가합니다. 기존 한국어 문구를 키로 사용하며 `{0}`, `{1}` 자리표시자의 번호와 개수는 번역에서도 유지합니다. 번역에서는 자리표시자 순서를 바꿀 수 있습니다.

```json
{
  "저장": "Save",
  "영역 {0} 체크섬 수정": "Repair region {0} checksum"
}
```

```tsx
import { t, formatMessage } from '../../../packages/save-core/src/i18n';

<button>{t('저장')}</button>
<span>{formatMessage('영역 {0} 체크섬 수정', [block])}</span>
```

새로운 동적 문구는 문자열 조각을 나누기보다 완전한 문장과 `formatMessage`로 작성합니다. 정적 필드 목록에는 원문 키를 보관하고 렌더링할 때 `t(field.label)`처럼 번역합니다. 모듈 초기화 시 번역 결과를 상수로 저장하면 언어 변경이 반영되지 않으므로 피합니다.

파일명·폴더 경로·버전은 번역 함수를 거치지 않고 원문 그대로 표시합니다. 저장 완료 문구에 포함되는 파일명도 `formatMessage`의 인자로 전달하여 재번역하지 않습니다. 옵션의 표시명만 번역하고 `value`, ID, 바이트나 저장 난이도 값은 바꾸지 않습니다. `t`는 기존 조합 문구와 공통 모듈 오류도 사전 패턴으로 번역합니다. 숫자·React 노드·바이트 배열처럼 문자열이 아닌 값은 그대로 반환하며, 미등록 문구는 원문으로 표시합니다.

## 게임 데이터와 데스크톱

캐릭터·직업·아이템·마법·지역·국가 이름과 아이템 설명은 `game-data/ko/`와 `game-data/ja/`의 ID별 파일을 사용합니다. 영어 게임 데이터는 없으므로 영어 선택 시 한국어 목록을 사용합니다. 내부 맵은 한국어의 상세 참고 레이블과 달리 일본어에서는 원문의 소속 지역명을 표시합니다. 구성과 조회 규칙은 [게임 이름 데이터](GAME_NAMES.ko.md)를 참고하세요.

네이티브 파일 대화상자의 제목·필터 이름은 선택 언어를 사용합니다. 메인 프로세스도 전달된 언어가 세 언어 중 하나인지 검사합니다. OS 기본 버튼과 시스템 오류 문구는 운영체제 언어를 따를 수 있습니다. 파일 경로·백업·읽기·쓰기 로직은 언어와 독립적입니다. Electron 패키지의 언어 리소스도 한국어·일본어·영어만 포함하며 GitHub Actions에서 해당 목록을 검사합니다.

## 확인

```powershell
npm test
npm run typecheck
npm run test:e2e -- --grep 'i18n|unsupported locale'
npm run build
```

단위 테스트는 사전 키·자리표시자·지역 코드·대체 언어·문구 조합을 검사합니다. UI 테스트는 자동 감지·전환·설정 유지·저장소 차단·확인창·편집 데이터 보존을 검사합니다. 기존 UI 테스트는 한국어 브라우저 언어를 지정하여 시스템 언어와 무관하게 실행합니다.
