# 게임 이름 데이터

## 언어별 파일

`packages/save-core/src/game-data/` 아래의 `ko/`와 `ja/`에 같은 이름의 JSON 파일을 보관합니다. 각 파일은 숫자 ID의 문자열 키와 이름을 연결하며, ID는 언어를 바꿔도 동일합니다.

| 파일 | 종류 | 일본어 이름 범위 |
|---|---|---|
| `character-names.json` | 캐릭터 이름 ID | 0~657, 658칸 |
| `class-names.json` | 직업 ID | 0~219, 220개 |
| `items.json` | 아이템 ID | 0~72, 73칸 |
| `spells.json` | 마법 ID | 0~43, 44칸 |
| `locations.json` | 지역 표시명 및 내부 맵의 소속 지역명 | 외부 0~100, 내부 256~512 |
| `internal-locations.json` | 내부 맵 표시명 | 256~511, 256칸 |
| `nations.json` | 국가명 | 0~16, 17개 |
| `item-descriptions.json` | 아이템 기본·대체 설명 | 0~72, 73쌍 |

이름 ID 0은 이름 없는 캐릭터를 뜻합니다. 아이템·마법 ID 0과 일부 빈 항목도 이름이 존재한다는 뜻이 아닙니다. 일본어 직업 ID 220~255는 `null`이며, 마법 ID 44~53에는 확인된 이름이 없어 빈 문자열을 유지합니다. 빈 이름이나 범위 밖의 ID는 기존 미확인 표시를 사용하며 다른 이름으로 임의 보충하지 않습니다. 마법 ID 43의 `？？？`는 이름 데이터의 실제 표기입니다.

기존 한국어 파일은 같은 구조의 `ko/` 폴더로 이동했으며 내용은 유지합니다. 두 언어의 이름이 다르더라도 이름끼리 대응시키지 않고 ID로 조회합니다.

## 조회와 표시

`game-names.ts`가 언어별 데이터를 선택합니다. `characterName`·`className`·`itemName`·`spellName`은 현재 화면 언어 또는 명시적으로 전달된 언어로 이름을 반환합니다.

- 한국어: `ko/` 목록
- 일본어: `ja/` 목록
- 영어: 영어 이름 목록이 없으므로 `ko/` 목록

일본어 파일의 반각 가나 원문은 그대로 보존합니다. 화면에서는 반각 가나 구간만 정규화합니다. 예를 들어 `ｱﾚｽ`는 `アレス`, `ｷﾝｸﾞ`는 `キング`으로 표시됩니다. 전각 물음표와 그 외 원문의 표기는 유지합니다.

이름 선택 목록은 `getCharacterNameOptions`·`getClassOptions`·`getItemOptions`·`getSpellOptions`로 렌더링 시 생성합니다. 기존 상수 목록은 한국어와 기존 ID를 유지하여 아이템 추가 검증·전체 아이템 획득 같은 편집 로직이 언어와 무관하게 동작하도록 합니다.

캐릭터 목록·파워랭킹·부대장 및 부대원 이름·캐릭터 편집·직업 선택·아이템 목록과 추가 선택·마법 목록에 같은 조회 함수를 사용합니다. 이름순 정렬은 일본어에서는 일본어 이름과 정렬 규칙을 사용합니다.

## 변경하지 않는 데이터

언어 선택이나 이름 표시는 세이브의 이름 ID·직업 ID·아이템 ID·마법 ID를 변경하지 않습니다. 이름 없는 캐릭터에 직업명을 대신 붙이지 않는 표시 규칙도 유지합니다. 국가명도 언어별 `nations.json`으로 조회하며, 부대 헤더 +05의 하위 니블로 국가를 선택하는 규칙과 색상은 유지합니다. 부대 목록·편성 화면·부대 편집의 국가 선택 목록에 같은 이름을 적용합니다.


## 지역명과 아이템 설명

일본어 외부 지역명은 0~100의 101칸입니다. 외부 ID 101~255에는 이름을 임의로 넣지 않습니다. 내부 맵은 ID별 소속 지역명 연결을 적용합니다. 일본어에는 개별 방 이름을 임의 번역하지 않으며, 같은 소속 지역의 여러 내부 ID가 같은 이름으로 표시될 수 있습니다. 한국어 내부 맵의 기존 상세 참고 레이블은 유지합니다.

개요·데스크톱 세이브 목록은 요약의 지역 문자열을 번역하는 대신 `locationId`로 현재 언어의 이름을 조회합니다. 공통 파서의 요약 문자열은 한국어로 유지하여 언어 변경이 파일 변경 감지의 비교 기준에 영향을 주지 않게 합니다. 부대 현재 위치·이동 목적지·이전 위치·캐릭터의 사망·포로·실종 위치 선택에도 같은 ID 조회를 사용합니다.

아이템 설명은 `description`과 `alternateDescription` 두 종류를 보관합니다. 기본 화면은 기존과 같이 `description`을 표시하며, API의 대체 설명 선택으로 다른 문구도 조회할 수 있습니다. AT·AR·DF·DR, 속성·가격 및 추천 정렬 점수는 기존 공통 정의를 유지합니다. 설명 문구가 다르다고 게임 효과 수치나 세이브 바이트를 변경하지 않습니다.
